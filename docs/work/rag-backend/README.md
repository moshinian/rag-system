# rag-backend Work

## Position

`rag-backend` 是当前项目的业务主系统，负责：

1. 知识库、文档、chunk 和问答记录。
2. 检索编排、prompt orchestration 和 RAG 主链路。
3. 异步索引、状态机、失败恢复、readiness gate 和运维语义。
4. 对 `rag-ai-service` 的模型能力调用编排。

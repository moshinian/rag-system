# rag-frontend Work

## Position

`rag-frontend` 负责把当前 RAG 主链路组织成工作台式企业后台界面，覆盖：

1. 知识库操作和状态展示。
2. 文档接入和索引观察。
3. 检索调试、问答展示和历史回放。
4. 健康检查和运维入口承接。
